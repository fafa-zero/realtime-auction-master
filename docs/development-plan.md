# 开发计划

## 第一阶段：最小可运行版本

- 使用内存数据保存商品、竞拍、出价和订单。
- 实现 HTTP API 查询竞拍快照。
- 实现 Socket.IO 出价和广播。
- 实现封顶价成交、自动延时和异常取消。

## 第二阶段：页面完善

- 增加主播管理后台。
- 增加用户端直播间 H5 页面。
- 增加竞拍历史和订单页面。
- 优化移动端样式。

## 第三阶段：持久化与并发优化

- 引入 MySQL / PostgreSQL。
- 引入 Prisma 管理数据表。
- 引入 Redis 保存竞拍实时状态。
- 使用 Redis Lua 脚本保证并发出价原子性。

## 第四阶段：测试与文档

- 补充接口测试。
- 编写压测脚本模拟多人出价。
- 整理系统设计文档、数据库设计文档和答辩材料。
